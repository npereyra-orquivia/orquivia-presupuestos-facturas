# Copias y recuperación

La automatización de copias se mantiene en una operación privada separada del código público del portal. Sus credenciales, destinos, claves de recuperación y evidencias no se publican en este repositorio.

Las herramientas de `scripts/backup/` se conservan como motor local anterior para uso manual por una operadora autorizada. Su presencia no activa un calendario ni acredita una copia o recuperación actual. No introducir credenciales administrativas en el navegador, código, PR ni logs.

Consulta [operación](OPERATIONS.md), [evidencia](BACKUP-EVIDENCE.md), [almacenamiento de copias](DRIVE-BACKUP.md) y [recuperación de acceso](ACCESS-RECOVERY.md).
