# Operación del portal

El código público contiene la aplicación y las comprobaciones de publicación. Los procedimientos de producción, automatización de copias, configuración administrativa y evidencias se mantienen en una operación privada separada.

Este documento no activa servicios ni acredita que una copia, un calendario o una recuperación estén operativos. La administradora debe consultar el registro privado vigente antes de ejecutar procedimientos o conceder permisos.

Consulta [copias y recuperación](BACKUP-RECOVERY.md), [recuperación de acceso](ACCESS-RECOVERY.md), [supervisión y avisos](MONITORING.md) y [publicación y pruebas](CI-SECURITY.md).
