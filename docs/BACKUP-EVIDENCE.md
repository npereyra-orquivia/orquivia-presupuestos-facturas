# Evidencia de copias y recuperación

Los resultados de las copias, sus verificaciones y los ensayos de recuperación se registran en la operación privada. No se publican aquí inventarios, identificadores, ubicaciones ni informes de producción.

Una prueba sintética o una subida correcta no equivale a una recuperación verificada. El estado debe contrastarse con la evidencia privada vigente.

Consulta [copias y recuperación](BACKUP-RECOVERY.md), [operación](OPERATIONS.md) y [supervisión](MONITORING.md).
